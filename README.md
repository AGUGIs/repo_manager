# Сервис управления репозиториями проектов

Учебный проект по дисциплине «Технологии разработки приложений на базе фреймворков».
Практическая работа № 1. Челышев Кирилл, группа ЭФБО-10-24.

## Предметная область

Управление репозиториями учебных и рабочих проектов: создание проекта,
привязка git-репозитория, назначение участников и проверка прав на действия
с кодом.

## Основные сущности

- пользователь
- проект
- репозиторий
- участник

## Текущий этап

В `main.py` реализован начальный программный сценарий:

- проверка видимости репозитория (публичный / приватный);
- проверка, не находится ли проект в архиве;
- проверка роли участника для действия с репозиторием;
- маскирование URL клонирования при выводе.

Сценарий использует простые типы данных (`str`, `bool`), операции со строками,
условные конструкции `if/else`, функции и импорт модуля `datetime`.

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate
python main.py
```
